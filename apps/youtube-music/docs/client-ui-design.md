# PSP クライアントの UI 設計

対象: `psp-client/app/src/`。PC 版 YouTube Music の見た目を
480x272 / ボタン操作に落とし込むための設計判断を残す。

## レイヤ構成

| ファイル | 役割 | 依存 |
|---|---|---|
| `theme.h` | 色 (ABGR) とレイアウト定数の唯一の定義場所 | なし |
| `gfx.c/h` | GU 初期化・フレーム制御・2D プリミティブ・手続きテクスチャ・フォント | theme |
| `ui.c/h` | アプリ共通部品 (背景・トップバー・chrome・再生バー) | gfx, art |
| `main.c` | 画面と状態機械のみ | gfx, ui, 各サブシステム |
| `art.c` | アートワークの取得・キャッシュ・描画・平均色 | gfx (描画は gfx に委譲) |

方針: **描画の「方法」は gfx、描画する「もの」は ui、いつ描くかは main。**
色やサイズを変えるときは theme.h だけを触れば全画面に効く。

## デザイン言語 (PC 版 YouTube Music × XMB)

- 配色は本家の実測値: 背景 #030303 / サブテキスト #AAAAAA /
  ホバー #282828 / ブランド赤 #FF0000
- 背景は「ほぼ黒 + 最上部だけ明るい」。明るい部分の色は
  **選択中アートワークの平均色** (`art_avg_color`) へ毎フレーム補間し、
  本家のコンテンツ色で染まるヒーロー背景を再現する
- 選択の表現は枠線ではなく **白い光彩 (ゆっくり呼吸) + 拡大イージング**。
  XMB の作法に合わせ、脈動はごく弱くする。非アクティブ段のカードは
  tint で減光してフォーカスの階層を作る
- 選択中カードの曲情報は **画面下の固定パネル** (`ui_selection_info`) に出す。
  カード直下に置く案は文字がカードやページ表示と被るため不採用
  (再生中は再生バーの上に細い帯として重ねる)
- はみ出すテキストは折り返さず `text_clipped` (シザーで切る) で処理する

### アニメーションは float 座標で描く

整数座標で拡大アニメーションを描くと 1px 刻みのジャンプになりカクつく
(62→72px の拡大がわずか 10 段)。`blit_tex` は頂点を
`GU_VERTEX_32BITF` の float にしてあり、サブピクセル位置に描けるので、
動くものは `art_draw_ex` / `gfx_glow` / `gfx_shadow` に float のまま渡す。

## 手続きテクスチャ (画像アセットを持たない理由)

起動時に CPU で生成し、アセット配布・ライセンス・ロード時間の問題を避ける。

- **ロゴ**: 赤円 + 白リング + 再生三角。距離関数 + 1px 減衰で AA
- **光彩**: 角丸ボックスからの距離の 2 乗減衰。白ティントで選択光彩、
  **黒ティント + 下オフセットで落ち影** (`gfx_shadow`) にも使う
- **角丸矩形**: サーバーが角丸化して送るアートワーク (r=7/64) と同じ丸み。
  プレースホルダ・進捗つまみなどの角丸塗りに使う

### ハマりどころ: 角丸カードの裏に draw_rect の影を敷かない

角のアルファが 0 のため、四角い影が角からはみ出して
「黒い謎の四角」に見える。影は必ず `gfx_shadow` を使う。
プレースホルダも同じ理由で `gfx_card_fill` (角丸) を使う。

## テキスト

- PGF に太字が無いので 0.6px ずらした 2 度描き (`text_bold`)
- 1 行クリップは `sceGuScissor` で実現 (`text_clipped`)。
  intraFont の Column 系は折り返してしまい、下の要素に被る
- 箱に収まらない 1 行を横に流すのは `text_scroll` (クリップ + 描画位置をずらす)

## 再生画面 (テレビ版に合わせた中央 1 カラム)

Apple TV の YouTube Music を基準にする。**再生を始めた瞬間の画面には
アートワーク・題名・アーティストしか置かない。**
シークバー・再生制御・評価・キューは十字キーの上下で呼び出すパネルに入れる。

- 上部バー (ロゴ・画面名・アカウント画像) と画面下の操作ヒント行は**出さない**。
  テレビ版の再生画面は全画面で、アートワークに画面を明け渡している
- 収まらない題名は折り返さず横に流す (`marquee_line`)。
  端で約 1.5 秒止めてから 0.4px/フレームで動かし、反対の端でも止めて戻る
- 一時的なお知らせ (ラジオ取得失敗・評価の送信失敗・対応する動画が無い・
  読み込み中・再生できない) は**アーティストの下の 1 行を取り合う**。
  優先順位を付けて必ず 1 つだけ描く。通常は何も出ない

### 十字キーの上下で出す操作パネル

出すとアートワークが上に詰まり、題名とアーティストは画面の一番上へ移る。
2 行目は **アーティスト・アルバム名・再生回数** を中黒でつないだもので、
取れなかった要素は詰めて書く (アルバムを持たない曲があるため)。

下は上から シークバー → ボタン → キュー。この 3 つを上下で行き来し、
左右はいる場所によって意味が変わる (シーク / ボタン選択 / キュー選択)。

ボタンはテレビ版から **チャンネル情報・コメント・Gemini を抜いたもの**。
左端に再生の操作 (前へ・再生/一時停止・次へ)、
右端に曲そのものへの操作 (高評価・低評価・保存・表示) を寄せる。
選んでいるものは白い丸で塗る (`gfx_circle_fill`)。

**「設定」は置かない。** テレビ版には画質の項目があるが、PSP は
480x272 の H.264 Baseline しかデコードできず、選べる画質が存在しない。
値を変えても画面が変わらない項目を並べるくらいなら、項目ごと出さない
(一度「標準 / 低」を入れて差し戻した)。

- 開閉は `g_panel_t` (0→1) で補間する。アートワークはこの値で
  位置と大きさが変わって上へ滑り、題名は中央と左上で濃さを交差させる。
  下の 3 つ (シークバー・ボタン・キュー) は少し下からせり上がる。
  **座標だけ動かして色を据え置くと、閉じ際に文字が居座って見える** ので、
  パネル側の描画は必ず `panel_fade()` を通す
- 映像を再生しているときはアートワークを描かず、映像の上に重ねる
- 一時的なお知らせは 2 行目 (アーティストの行) を明け渡して出す。
  パネルの下側は詰まっていて、割り込む場所が無いため
- 「表示」のシートは、テレビ版では画面を右に縮めて左に一覧を出すが、
  480x272 で縮めると何も見えなくなるので、暗くした上に一覧だけ重ねる
- **再生できない曲は 2 秒ほど理由を出してから自動で次へ送る。**
  Premium 限定として配信されている音源は Cookie が無いと取れず、
  そのままだとキューがそこで止まる。全部失敗する場合に送り続けないよう、
  連続失敗は 3 曲までで打ち切る
- **単曲を選んだときはラジオをキューにする** (`queue_from_single`)。
  1 曲だけのキューにすると終わった時点で止まり、「次の曲」も出ない。
  本家も 1 曲を選ぶとその曲から続くミックスが流れる

### 背景のぼかしはシェーダを書かない

64x64 のアートワークを平均で 16x16 まで縮め、画面いっぱい (480x480 を
上下にはみ出させて配置) に引き伸ばす。`sceGuTexFilter(GU_LINEAR, ...)` が
30 倍に拡大する過程でそのままぼかしになるので、ぼかし処理を自分で書かなくてよい
(`art_draw_blur_bg`)。

**角のアルファを 255 に上書きすること。** アートワークは角丸のため四隅が
透明で、そのまま敷くと背景に穴が空く。
